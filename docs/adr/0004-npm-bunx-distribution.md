# Public npm package executed with bunx

The user-facing distribution is a public npm package whose executable is launched by `bunx --bun`; `@latest` is for trial and persistent MCP configurations pin an exact version. This preserves one-line installation and automatic stdio startup across harnesses while keeping Bun as the runtime. A compiled/notarized macOS artifact remains optional because Bun.WebView compilation and the separately downloaded Obscura sidecar require additional release proof.
