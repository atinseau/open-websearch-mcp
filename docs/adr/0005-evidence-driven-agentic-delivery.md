# Evidence-driven autonomous delivery through worktrees

Implementation is coordinated by one durable OpenCode orchestrator that delegates every bounded task to isolated worktrees, challenges substantive decisions before code, requires independent spec and quality reviews, and persists progress in Git-backed checkpoints. A single long agent session was rejected because model context, crashes, and self-review cannot prove completion. The loop continues through repair and redesign until all requirements are verified, stopping early only for a falsifiable external-authority blocker.
