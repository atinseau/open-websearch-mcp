# Teacher WebSearch fixtures with deterministic grading

Codex and Claude native WebSearch runs establish a versioned high-quality baseline, but no LLM participates after fixture creation or inside the product. Observable traces are cross-curated once into claims, evidence, and acceptable source equivalents; local tests then grade deterministically. This preserves provider-level ambition without making tests nondeterministic, paid per run, or dependent on one teacher's URLs as truth.
