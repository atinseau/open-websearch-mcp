# Google front-end discovery with mandatory Obscura rendering

Open WebSearch uses Google's public front end for live candidate discovery and a pinned local Obscura stealth process for every rendered destination. Building a Brave/Exa-scale index is outside a personal local product, while APIs would violate the no-search-service requirement; curl-style fetching cannot render the pages the product exists to recover. Obscura is therefore mandatory and failures remain explicit rather than triggering a weaker renderer.
